Reformat data so that route number and route name are distinct
variables.

When reshaping the data, I found that the route variables had different
data types. Route1 to Route7 were stored as character variables, while
Route8 to Route11 were stored as numeric variables. So i use mutate to
change the data type.

``` r
subway_data_reformatted =
  subway_data |> 
  mutate(
    route8 = as.character(route8),
    route9 = as.character(route9),
    route10 = as.character(route10),
    route11 = as.character(route11)
  ) |> 
  pivot_longer(
    route1:route11,
    names_to = "route_number",
    values_to = "route_name"
  )
```
